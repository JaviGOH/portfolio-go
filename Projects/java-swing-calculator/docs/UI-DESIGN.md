# UI Design

## Objective

The goal of this redesign is to improve the user interface of the Java Swing Calculator while keeping the application simple, clean and easy to use.

The design should reflect the level of a first-year DAM project, focusing on readability, consistency and usability rather than advanced visual effects.

---

## Design Style

- Dark theme
- Minimalist interface
- Clean and simple layout
- Easy to read
- Classic calculator arrangement

---

## Color Palette

Planned colors:

- Window background: Dark gray
- Calculator display: Light green
- Number buttons: Gray
- Operation buttons: Dark gray
- Clear button (C): Light green
- Equals button (=): Green

The calculator will use a dark theme with green accents to create a clean and distinctive visual identity. The display and the equals button will share the same color family to emphasize the result of each calculation.

---

## Typography

- Font: Sans Serif
- Clear and readable text
- Larger font for the calculator display

---

## Layout

The calculator layout will follow the traditional arrangement:

7 8 9 /
4 5 6 *
1 2 3 -
C 0 = +

The display will be placed at the top of the window and the buttons below it.

---

## Future Improvements

Possible improvements for future versions:

- Rounded buttons
- Custom application icon
- Better spacing between components
- Keyboard support
- Light/Dark theme switch
