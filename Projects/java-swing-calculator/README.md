Java Swing Calculator

A desktop calculator application built with Java and Swing, following the MVC (Model-View-Controller) architecture.

This project is part of my personal portfolio and aims to demonstrate clean code organization, separation of concerns, and basic desktop UI development in Java.

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clean graphical user interface using Java Swing
- MVC architecture separation
- Error handling for invalid operations

## Technologies

- Java
- Swing (GUI)
- MVC design pattern
- Git & GitHub

## Project Goal

The main objective of this project is to practice object-oriented programming and software design principles by building a simple but well-structured desktop application.
